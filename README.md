# Python Student Toolkit

Small Python command-line programs that demonstrate the fundamentals behind larger software: validation, reusable functions, file handling, and predictable output.

## Included scripts

| Script | Demonstrates |
|---|---|
| `src/calculator.py` | Functions, validation, arithmetic dispatch |
| `src/password_strength.py` | String inspection and rules |
| `src/expense_tracker.py` | CSV file handling and totals |

Run any script with Python 3. The examples use only the standard library.
